# CRUD-сервер на Servlet API

## 📋 Описание задачи

Реализовать **In-Memory CRUD-сервер** на базе Java Servlet API с потокобезопасным 
репозиторием. Сервер поддерживает операции **Create, Read, Update, Delete** 
над постами.

Задачи:
1. Провести **рефакторинг** кода: вынести строковые литералы в константы, 
   убрать дублирование.
2. Реализовать **репозиторий** с учётом **конкурентного** доступа 
   (методы могут вызываться из разных потоков).
3. Реализовать логику `save()`:
   - `id=0` → создание нового поста (с присвоением нового `id`).
   - `id!=0` → обновление существующего поста.

## 🎯 Цель

Отработать:
- Написание сервлетов и работу с Servlet API;
- Понимание жизненного цикла сервлета;
- Потокобезопасную работу с коллекциями (`ConcurrentHashMap`, `AtomicLong`);
- Рефакторинг кода: константы, устранение дублирования;
- Обработку HTTP-запросов (`GET`, `POST`, `PUT`, `DELETE`).

## 🛠️ Используемые технологии

- Java 17+
- Servlet API (`HttpServlet`, `HttpServletRequest`, `HttpServletResponse`)
- Jetty (или Tomcat) — контейнер сервлетов
- Maven
- `ConcurrentHashMap` / `AtomicLong` для потокобезопасности
- Gson (или Jackson) для сериализации JSON
